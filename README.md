**DayTrip Lombok** adalah platform web landing page modern dan interaktif yang dirancang untuk mempromosikan destinasi wisata unggulan serta layanan paket tur harian di Pulau Lombok, Indonesia. Landing page ini mengutamakan pengalaman pengguna (*user experience*) yang responsif, visual estetis, serta kemudahan proses pemesanan tiket/paket wisata.

🚀 **Live Demo:** [https://daytriplombok.netlify.app/](https://daytriplombok.netlify.app/)

## ✨ Fitur Utama

- 📱 **Desain Fully Responsive:** Tampilan optimal di berbagai perangkat (Smartphone, Tablet, hingga Desktop).
- 🗺️ **Katalog Destinasi Populer:** Menampilkan destinasi eksotis Lombok seperti Pantai Kuta, Senggigi, Gili Trawangan, dan Gunung Rinjani lengkap dengan estimasi harga.
- 📝 **Formulir Pemesanan Interaktif:** Sistem input pemesanan tour langsung dari website dengan validasi tanggal dan jumlah peserta.
- 🌟 **Ulasan & Testimoni Pelanggan:** Menampilkan impresi dan ulasan dari wisatawan yang telah menggunakan layanan.
- 🧭 **Navigasi Smooth Scroll:** Perpindahan antar seksi halaman yang mulus dan nyaman.
- 💬 **Integrasi Kontak & Media Sosial:** Akses cepat menuju layanan WhatsApp/Call Center dan tautan media sosial resmi.

## 🛠️ Teknologi yang Digunakan

Proyek ini dibangun menggunakan teknologi web standar tanpa dependensi berat untuk memastikan performa yang cepat dan efisien:

- **Frontend Core:**
  - `HTML5` - Struktur semantik halaman web
  - `CSS3` - Layouting, Flexbox/Grid, Responsive Media Queries, & Custom Styling
  - `JavaScript (ES6)` - Manipulasi DOM, interaktivitas form, dan smooth scrolling
- **Aset & Ikon:**
  - [Font Awesome](https://fontawesome.com/) - Ikon antarmuka
  - [Google Fonts](https://fonts.google.com/) - Tipografi
- **Hosting / Deployment:**
  - Netlify Continuous Deployment
