**Nurul Haramain** adalah platform web landing page modern dan interaktif yang dirancang untuk memberikan informasi mengenai profil, program pendidikan, fasilitas, serta kegiatan keagamaan dan sosial di Pondok Pesantren / Yayasan Nurul Haramain. Landing page ini mengutamakan pengalaman pengguna (*user experience*) yang responsif, visual yang rapi dan estetis, serta kemudahan akses informasi bagi para calon santri, wali murid, dan masyarakat umum.

🚀 **Live Demo:** [https://nurulharamain.netlify.app/](https://nurulharamain.netlify.app/)

---


## ✨ Fitur Utama

- 📱 **Desain Fully Responsive:** Tampilan optimal dan adaptif di berbagai perangkat (Smartphone, Tablet, hingga Desktop).
- 🎨 **User Experience (UX) Modern:** Antarmuka intuitif, bersih, dan nyaman dibaca dengan pemilihan tipografi serta warna yang harmonis.
- 📚 **Katalog Program Pendidikan & Kegiatan:** Informasi lengkap mengenai jenjang pendidikan, program unggulan, dan kurikulum santri.
- 📰 **Portal Informasi & Pengumuman:** Kemudahan dalam mengakses berita terbaru, jadwal kegiatan, dan pengumuman penting.
- 🧭 **Navigasi Smooth Scroll:** Perpindahan antar seksi halaman yang mulus untuk meningkatkan kenyamanan penjelajahan.
- 💬 **Integrasi Kontak & Media Sosial:** Tautan langsung menuju layanan WhatsApp, formulir kontak, dan media sosial resmi.

## 🛠️ Teknologi yang Digunakan

Proyek ini dibangun menggunakan teknologi web standar yang ringan dan dioptimalkan tanpa dependensi berat untuk memastikan kecepatan serta efisiensi performa:

- **Frontend Core:**
  - `HTML5` - Struktur semantik dan aksesibel untuk halaman web
  - `CSS3` - Custom styling, Flexbox/Grid, Responsive Media Queries, & Animasi halus
  - `JavaScript (ES6)` - Interaktivitas antarmuka, manipulasi DOM, dan navigasi intuitif
- **Aset & Tipografi:**
  - [Font Awesome](https://fontawesome.com/) / Remix Icons - Ikonografi antarmuka
  - [Google Fonts](https://fonts.google.com/) - Tipografi web modern
- **Hosting / Deployment:**
  - Netlify Continuous Deployment
